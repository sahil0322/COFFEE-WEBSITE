#  SIGMAA Beans - E-Commerce Platform

A full-stack, responsive e-commerce web application for an artisanal coffee shop. This project features a dynamic front-end UI, a custom shopping cart, a live database for product management, and secure checkout processing.

##  Features
* **Dynamic Menu & Shop:** Products are fetched live from a MongoDB cloud database via a RESTful API.
* **Interactive Shopping Cart:** Custom JavaScript handles state management for adding items, calculating totals, and dynamic UI updates.
* **Secure Checkout:** Integrated with the Stripe API to handle secure, PCI-compliant payment sessions.
* **Responsive Design:** A custom, modern UI built with HTML5, CSS3 Grid/Flexbox, ensuring a seamless experience across desktop and mobile.

##  Tech Stack
* **Front-End:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Back-End:** Node.js, Express.js
* **Database:** MongoDB Atlas, Mongoose
* **Payments:** Stripe API
